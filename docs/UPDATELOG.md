# 업데이트 내역

## 2026-11-08
- 구현 계획 문서를 새로 만들었어요. (`docs/plans/2026-11-08-cleanup-pwa-profile-multi.md`)
- 쌓였던 파일들을 정리했어요. 쓰지 않는 랭킹 창 파일과 이전 방식 파일을 지우고, 중복 이미지를 하나로 합쳐서 전체 용량을 65MB에서 약 7MB로 줄였습니다.
- 방만들기 기록 지키기를 조금 단단히 했어요. 방 정보가 이상하면 저장되지 않고, 방 번호도 한 번 더 확인합니다.
- 게임이 멈추면 다시 시도할 때 깔끔하게 다시 시작하도록 했어요.
- 앱으로 설치할 수 있게 했어요. 인터넷이 느려도 앱처럼 빠르게 열리고, 업데이트도 자동으로 받아옵니다. 공유 버튼으로 설치하는 방법도 안내해요.
- '내 기록' 버튼을 만들었어요. 내 이름으로 등록한 점수 최고 기록, 최근 기록, 1등 횟수를 한눈에 볼 수 있어요. 회원가입이 필요 없어요.
- 눈싸움 서바이벌 대결이 더 편해졌어요. 열린 방 목록을 보고 바로 들어가고, 초대 링크를 복사해 친구에게 보낼 수 있으며, 관전 모드로 보기만 할 수도 있어요. 혼자 하고 싶으면 AI와 바로 대결할 수 있어요.

## 2026-11-07
- 단기~중기 개선 계획 문서를 만들었어요. (`docs/plans/2026-11-07-short-midterm-improvement-plan.md`)
- 명예의 전당 별도 랭킹 창(`leaderboard.html`)을 하나로 합치고, 점수가 안전하게 표시되도록 바꿨어요.

- 프로젝트 안내문(README)과 업데이트 내역 파일을 만들었어요.
- 단기~중기 개선을 구현했어요: 점수 등록 공용화(테트리스·벽돌 깨기), 전역 음소거 동기화, 게임 딥링크(?game=), 레지스트리 자동 검증, 린트·테스트·CI, 키보드/Esc 접근성, 이미지 경량화로 용량을 약 60MB에서 7MB로 줄였어요.
- 점수 기록 보호 규칙을 실제로 배포했어요. 점수가 줄어들거나 기록이 삭제되지 않음을 확인했어요.
- 전체 35개 게임에 공용 점수 등록 폼을 적용하고, 상단 음소거 버튼이 모든 게임 효과음에 동시에 적용되도록 했어요.
- 5개 친구 대결 게임의 연결 안정성을 개선했어요. 방장이 나가면 자동으로 알려줘서 무한히 기다리는 일이 없어졌고, 방 번호 복사·대기 명단·다시 시작 흐름이 매끄러워졌어요.
